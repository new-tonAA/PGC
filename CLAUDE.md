## Git Rules — READ FIRST
- **NEVER `git push --force`** — this destroys remote history
- **NEVER commit** without explicit permission from the user (e.g. "commit", "提交")
- **NEVER push** without explicit permission from the user (e.g. "push", "推送")
- **NEVER touch the remote** (push/pull/fetch) without explicit permission
- **Always ask before any git operation that modifies remote**
- `git reset --hard` is OK locally, but don't push it without asking
